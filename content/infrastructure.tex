\section{Independent Infrastructure Project}

\entry{\href{https://arthurdanjou.fr/projects/artlab}{ArtLab: Personal Homelab}}{2023--present}
  {Self-hosted infrastructure for DevOps, distributed systems and MLOps experimentation}
\begin{itemize}
  \item Operate Proxmox virtual machines and LXC containers alongside Docker
    services across multiple hosts. Version service configurations in Git and
    automate deployments through Dockhand.
  \item Manage NAS-backed storage and S3-compatible object storage, with
    infrastructure backups through Proxmox Backup Server and application
    backups using restic.
  \item Configure private Tailscale networking, TLS and single sign-on for
    service access; monitor resource usage and availability with Beszel and
    Uptime Kuma.
\end{itemize}
